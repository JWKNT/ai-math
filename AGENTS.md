# AI Math Results

Read `../site-theme/AGENTS.md` and select a skill from `../site-theme/SKILLS.md`.
Use `jehlp-math-explainer` for each page and `jehlp-site-design` for layout.

Change a body in `content/`, a figure in `lib/figures.mjs` or the frame in `lib/pages.mjs`, then run `npm test`.
The test rebuilds every page. Commit the source and the generated pages together.
Keep an exact check in `tests/site.test.mjs` for each calculated number on a page.

## Original technical writing

Use ASD-STE100 Issue 9 for original explanatory text, instructions, and interface text.
Read `../site-theme/docs/WRITING-STYLE.md` before a prose change.
Paraphrase sources. Write "reports" for a claim that human experts have not confirmed.
Report the checks performed. Do not claim full compliance without a dictionary and rule review.
